# Bash File Organizer

A Bash script that organizes files into folders based on their file extensions.

## Features

- Organizes audio files.
- Organizes video files.
- Organizes image files.
- Moves other regular files into a document folder.
- Supports uppercase and lowercase file extensions.
- Creates destination folders automatically.

## Usage

```bash
chmod +x organizer.sh
./organizer.sh /path/to/directory
```

## Requirements

- Linux
- Bash

## Disclaimer

Test the script on a sample directory before using it on important files.
